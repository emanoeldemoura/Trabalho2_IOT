Tópicos

Cada tópico tem um único publicador

sis1a/emanoel_iot/posto01/geladeira01/
├─ telemetria  ESP32  → painel
├─ estado      ESP32  → painel  (retido)
├─ alerta      ESP32  → painel
├─ comando     painel → ESP32   (assinado)
├─ ack         ESP32  → painel
├─ lote        ESP32  → nuvem   (assinado)
├─ lote_ack    nuvem  → ESP32   (assinado)
└─ config      nuvem  → ESP32   (assinado)

Broker test.mosquitto.org — TLS 8886 (ESP32) e WSS 8081 (painel).

Tópicos MQTT

Formato de cada mensagem. Só o tópico comando pode ser enviado daqui — os demais são publicados pelo ESP32 ou pela nuvem.

Rotas HTTP do Worker

https://vacinasegura.emanoel-moura.workers.dev — rotas de gravação exigem token (sem token: 401).

Limites da geladeira

Gravados na nuvem (KV). O ESP32 recebe os novos valores em até 1 minuto, sem regravar a placa.

No modo demonstração o ESP32 usa tempos curtos fixos (20 s e 10 s).

Modo de operação

Real: 5 min / 1 min · Demonstração: 20 s / 10 s

Credenciais

Ficam só neste navegador e nunca são enviadas pelo MQTT.
